# Power Regulator + LED Shield PCB for Arduino Uno

An Altium Designer project involving the schematic design of an Arduino Uno-compatible power regulator and LED shield, including a TPS562201-based power stage, Arduino header interfacing, component selection, and custom Arduino header footprint creation based on the Uno datasheet.

## Tools Used

- Altium Designer
- Schematic Capture
- PCB Libraries
- Arduino Uno Datasheet

## Project Highlights

- TPS562201-based power regulation stage
- Arduino Uno-compatible header interfacing
- LED shield circuit
- Component selection based on datasheets
- Custom Arduino header footprint creation
